# Daily Fun Game - Star Catcher 🌟

A simple, colorful browser game where you catch falling stars and avoid asteroids!

## How to Play
- Open `index.html` in any browser
- Use ← → arrow keys or A/D to move your spaceship
- Catch yellow stars for points
- Avoid red asteroids or lose a life
- 3 lives – how high can you score?

## Controls
- Left: ArrowLeft or A
- Right: ArrowRight or D

Made as part of the "Everyday Fun Game" series. Enjoy!
